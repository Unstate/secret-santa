# Архитектура фронтенда

FSD (Feature-Sliced Design). Фичи разрозненные, проект делают два разработчика —
структура обязана позволять делать свои фичи и не мешать друг другу: фичи
изолированы, общее живёт в `shared`, пересечения только через публичные
`index.ts` слоёв.

## Слои и ограничения импортов

| Слой | Что лежит |
|---|---|
| `app` | ядро сайта: вход (`main.tsx`), глобальные стили, конфигурация роутера |
| `features` | функциональный слой: все функции, каждая не зависит от другой |
| `widgets` | скомпонованные UI-компоненты (из фич и shared) |
| `pages` | страницы: композиция виджетов и фич для маршрута |
| `shared` | переиспользуемое: `ui` (компоненты), `api` (запросы), `hooks` (кастомные хуки), `lib` (утилиты) |

Импорты снизу вверх: `shared` могут импортировать все, `app` — никто.
Запрещены импорты между соседями одного уровня: фича не импортирует фичу,
страница — страницу (пересечение фич = через общий `shared` или композицию
на странице/виджете).

## Папки

```
frontend/src/
  app/
    core/          main.tsx — вход приложения
    router/        конфигурация роутера (Router.tsx)
    styles/        глобальные стили: reset, theme (токены), variables
  features/
    <feature>/     одна функция = одна папка (форма, сценарий)
  widgets/
    <widget>/      скомпонованные блоки UI
  pages/
    <page>/        страница: tsx + scss, без вложенных папок
  shared/
    api/           запросы: api.ts — класс с базовыми функциями запросов (DI),
                   рядом типы и готовый инстанс
    hooks/         кастомные хуки
    lib/           утилиты без React (деньги, валидация, тема)
    ui/            компоненты: каждый в своей папке <Name>/
```

## Соглашения

- **Индекс-файл.** `index.ts` есть только у разделов — `features`, `pages`,
  `shared/ui`, `shared/api`, `shared/lib`, `shared/hooks`: он собирает их
  публичное. Внутри раздела импорты идут напрямую в файл:
  `import { Button } from '@/shared/ui'`, но
  `import { Spinner } from '../Spinner/Spinner'`.
- **Компонент.** `shared/ui/<Name>/` — `Name.tsx` + `Name.module.scss`,
  без `index.ts`. Страница — `pages/<page>/<PageName>.tsx` + `.module.scss`.
- **Стили.** SCSS-модули рядом с компонентом; цвета/радиусы/тени — только
  токены из `app/styles/theme.scss` (светлая и тёмная темы через
  `[data-theme]`), никаких хардкод-цветов.
- **Комментарии.** Только там, где без них не понять код; никаких описаний
  очевидного.
- **Сессия.** Токен игрока — в IndexedDB (следующий этап), чтение токена
  внутри `shared/api`.
